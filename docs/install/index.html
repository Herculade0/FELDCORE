Install answer file

This file is not encrypted. The administrator password, the setup code, and the WiFi password are written in the clear on the USB stick until the first boot deletes the file. Deleting the file does not scrub those bytes from the stick. Use an SSH public key instead of a password.

Signed OS image

Download the latest signed appliance image from the GitHub release. This page does not fetch it for you.

The OS image does not install sudo. Checking this records the choice; the account is still created and sudo is skipped until the package exists.

Data pool

This records the choice only. The answer file does not partition the disk. Uncheck it to decline the pool.



  
Where the file goes

  
Decompress the image and copy feldcore-install.json onto the EFI partition, volume label FC-ESP, at feldcore/feldcore-install.json. The partition starts 1 MiB into the image this repository builds. Nothing on this page is uploaded.
