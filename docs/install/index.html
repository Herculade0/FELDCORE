A FELDCORP SYSTEM

Install answer file

This file is not encrypted. The administrator password, the setup code, and the WiFi password are written in the clear on the USB stick until the first boot deletes the file. Deleting the file does not scrub those bytes from the stick. Use an SSH public key instead of a password.

Answer file

Network
WiFi

Leave the network name empty to stay on the wired port.

Web administrator

Leave the username and password blank and this file will not set an administrator. The device then prints a random setup code on the console.

SSH
Data pool

This records the choice only. The answer file does not partition the disk. Uncheck it to decline the pool.



  
Where the file goes

  
Put feldcore-install.json on the Ventoy data partition, or on a second FAT or exFAT stick, at feldcore/feldcore-install.json or at the volume root. Boot feldcore-installer.iso and run feldcore-install. The installer copies the file onto the new system. Nothing on this page is uploaded.
