This guide is not ready to walk a backup from start to finish. Other work on backups is still landing, and this page will not pretend the steps are settled.

What is already on the server is a **Proton Drive backups** card under Settings → Network. It is marked experimental there. The card, what it copies, and what it refuses to copy are described in [[help:proton|Proton Drive and Mail]].

[[route:settings.drive|Open Proton Drive backups]]

Container snapshots are a different thing. They put one container back to an earlier point. They are not a backup of the machine. [[help:snapshots|Snapshots]] covers them.

[[help:backups|Backups]] is the placeholder for everything past that Proton Drive card.
