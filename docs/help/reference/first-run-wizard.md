This topic is marked coming soon because the wizard is still being worked on. A full click-by-click would go stale.

After the administrator account exists, a wizard can open before the normal pages. The steps it knows are this server, network, storage, software, shares, security, updates, and a summary. You can change the host name, address, services, firewall, and update checks later in Settings.

[[route:settings|Open Settings]]

[[help:getting-started|Get started]] covers the setup code and the account, which come before the wizard.

> [!NOTE]
> If you do not see a wizard, the account is already past that step, or this install was started with the wizard skipped. You have not lost a page. Use Settings.
