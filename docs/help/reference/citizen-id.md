Citizen ID is not in the app. There is no Citizen ID page, and this Help article does not describe one.

The Publish form already has a Citizen ID menu (`public`, `signed-in`, `groups`, `admins`). The value is stored on the published app. The form says enforcement waits until Citizen ID is connected. Until then, the protection rules still run, and that menu does not block anyone.
